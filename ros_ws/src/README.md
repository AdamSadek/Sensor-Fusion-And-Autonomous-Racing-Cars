# Correctly Installing Packages 
After the repos are cloned in _`./src`_, we need to install the packages.
- _transport_driver_: [Transport Driver Installation Intructions](https://github.com/ros-drivers/transport_drivers/tree/foxy?tab=readme-ov-file#quick-start)
- _v4l2_camera_: [v4l2_camera Installation Intructions](https://gitlab.com/boldhearts/ros2_v4l2_camera#installation)
- _vision_opencv_: [vision_opencv Installation Intructions](https://github.com/ros-perception/vision_opencv/tree/rolling/cv_bridge#installation)
- _image_common_ package, depencency for the v4l2_camera.
- _image_transport_plugins_ package, depencency for the v4l2_camera.
- _vision_opencv_ package: [VESC Installation Intructions](https://github.com/f1tenth/vesc/tree/foxy?tab=readme-ov-file#veddar-vesc-interface)

## !These sub-repositories are required components for the project!
